# Лабораторная №3: требования и демонстрация

Основной источник: `Lab #3 Texture mapping.pdf`, 3 страницы. Лекции уточняют способ реализации, но не добавляют обязательных возможностей.

| Требование | Источник | Как проверить |
| --- | --- | --- |
| Продолжение предыдущей работы, объекты своего варианта | PDF, стр. 1–2 | Сопоставить геометрию и возможности с `lab2`; запустить существующие математические и input-тесты |
| Vulkan, GLFW, ImGui; работа в реальном времени | PDF, стр. 1 | Проверить зависимости и отрисовку; подвигать камеру и изменить параметры через интерфейс |
| Альбедо из файлов, загрузка сторонним декодером | PDF, стр. 1 | Проверить код декодирования и комплект ресурсов; запускать из другого рабочего каталога |
| Позиция, нормаль и UV в вершине | PDF, стр. 1 | Проверить vertex layout, передачу UV в шейдер и тесты UV |
| Обычная выборка одной альбедо без дополнительных эффектов | PDF, стр. 2–3, базовое задание | Отключить эффект, выбрать один материал у всех моделей и проверить обычное текстурирование |
| Свойства моделей в uniform buffer, без матриц в push constants | PDF, стр. 2 | Проверить CPU/GLSL структуры и привязку UBO |
| Один dynamic UBO, смещение модели в команде привязки descriptor set | PDF, стр. 2–3 | Проверить `UNIFORM_BUFFER_DYNAMIC`, stride по лимиту устройства и dynamic offset; запустить тесты выравнивания |
| Вершинные и индексные данные в памяти GPU через staging и GPU copy | PDF, стр. 2 | Проверить флаги памяти, `TRANSFER_DST`, staging и команды копирования |
| Разные текстуры, выпадающий выбор отдельно для каждой модели | PDF, стр. 1 и 3, доп. 1 | Назначить моделям разные материалы и убедиться, что изменения независимы |
| Свой descriptor set для каждого материала | PDF, стр. 3, доп. 1 | Проверить выделение и привязку наборов по материалам |
| Нетривиальное семплирование: модуляция цвета, несколько чтений того же изображения по разным UV, зависимость от времени | PDF, стр. 3, доп. 2 | Проверить fragment shader; включить эффект у одного объекта, наблюдать изменение во времени и отсутствие изменений у соседнего |
| Управление эффектом через push constants | PDF, стр. 2–3, доп. 2 | Проверить флаг/параметры, `VkPushConstantRange`, `vkCmdPushConstants` и условие в шейдере |
| Specular map ограничивает области блика | PDF, стр. 3, доп. 3 | Подвигать источник/камеру, сравнить текстурную маску и видимые блики |
| Emissive map прибавляется после Blinn–Phong, без освещения | PDF, стр. 3, доп. 3 | Выключить все источники и ambient; свечение должно остаться в областях emissive |
| Отсутствующие specular/emissive заменяются чёрной текстурой 1×1 | PDF, стр. 3, доп. 3 | Проверить дескрипторы fallback; материал без карт не должен светиться и давать текстурный блик |

На «5» требуются базовое задание и все три дополнительных. В формулировке оценки «4» есть редакционная несогласованность: «первые три» дополнительных при трёх заданиях всего и пометке третьего «на 5». Для полного выполнения это ничего не меняет.

Новые объекты, пол и стены, mipmaps, анизотропия, online-генератор specular и генерация emissive именно шумом Перлина не обязательны. В полном варианте push constants нужны для эффекта; требование базового задания не переносить в них свойства моделей сохраняется.

## Подходы из лекций

| Лекция и слайды | Применимый подход |
| --- | --- |
| #5, 12–19 и 34 | UV, интерполяция, фильтрация и адресация за пределами `[0,1]` |
| #5.2, 2–9 | Файловый декодер → RGBA8; GPU image, image view и sampler |
| #5.2, 11–22 | Staging, one-shot command buffer, копирование и барьеры `UNDEFINED → TRANSFER_DST → SHADER_READ_ONLY`; ожидание fence перед освобождением staging |
| #5.2, 23–26 | Combined image sampler в дескрипторах, UV и `texture()` во fragment shader |
| #6, 2–11 | Dynamic UBO, выравнивание по `minUniformBufferOffsetAlignment`, offset при `vkCmdBindDescriptorSets` |
| #6, 13–15 | Вершинный/индексный GPU-буфер с `TRANSFER_DST`, загрузка через staging |
| #6, 16–18 | Push constants для переключения ветки шейдера |

`tests/math_tests.cpp` сохраняет проверки геометрии додекаэдра, камеры, проекций, нормалей и конуса света из второй работы. `tests/texture_tests.cpp` проверяет конечность и диапазон UV, ненулевые площади и winding, единую аффинную проекцию на грань, покрытие пятиугольника, выравнивание UBO и его граничные случаи. Эти проверки не заменяют визуальный запуск и проверку Vulkan validation.

## Итоговая сверка

Все строки таблицы сверены с реализацией и фактическими проверками. `tests/verify.ps1`
прошёл в Debug и Release: три CPU-теста, 41 GPU-сценарий (192 кадра) и ещё по 120
кадров в трёх размерах окна. Синхронизационная валидация Vulkan была включена,
предупреждений и ошибок не было. GPU-тест проверил DEVICE_LOCAL у геометрии и
текстур, выравнивание и границы общего UBO, разные сочетания материалов,
рост и очистку источников, обе проекции, неравномерный масштаб и resize.
Все четыре SPIR-V модуля прошли `spirv-val`.

В окне приложения проверены обычный режим, независимый выбор текстуры,
изменение эффекта во времени, влияние specular и свечение без освещения.
Отключение emissive убирает светящиеся полосы; материал с чёрным fallback
остаётся чёрным без освещения. Снимки сохранены в `report/`.
Перенесённая папка запуска работает из другого каталога, в том числе по пути
с пробелами и кириллицей. Отсутствующий ресурс вызывает понятную ошибку запуска.

Проверено на AMD Radeon(TM) Graphics. Другие GPU и ОС отдельно не проверялись.
Эталонная `lab2` не изменялась.
