# Лабораторная №3. Текстурирование

Вариант 10 — правильный додекаэдр. C++20, Vulkan, GLFW и ImGui.

Добавлены текстуры кирпича, металла и плитки с выбором для каждой фигуры,
анимированное сэмплирование, карты блика и свечения. Камера, освещение
и анимация фигур остались из второй работы.

## Запуск

Открыть `BUILD.cmd`, затем `RUN.cmd`. Нужны Visual Studio 2022 с C++, CMake
и Vulkan SDK (`VULKAN_SDK`). В CLion открыть `lab3`, выбрать toolchain
Visual Studio и цель `vulkan-starter-app`.

Камера: WASD — движение, Q/E — вниз и вверх, правая кнопка мыши — поворот.
Остальные настройки камеры, света и анимации находятся в ImGui.

В разделе `Textures` можно выбрать материал, включить анимированное
сэмплирование, блик и свечение. Флажок `Lighting` выключает освещение,
чтобы посмотреть свечение в темноте.
